# 🌲 Лес (выживание) — сервер

## Запуск
1. Установи Node.js (версия 16 или новее): https://nodejs.org
2. В папке проекта выполни `node server.js` (или `npm start`). На Windows можно дважды кликнуть `start.bat`.
3. Открой в браузере http://localhost:3000

Установка пакетов (`npm install`) не нужна — зависимостей нет.

## Игра с друзьями
- В одной Wi-Fi сети: друзья открывают `http://<IP-твоего-компьютера>:3000`.
- Через интернет: залей папку на хостинг с Node.js (Render, Railway, Fly.io, VPS) и запусти там `npm start`.
  Порт берётся из переменной `PORT`. Игра сама подключается к WebSocket на том же адресе (ws:// или wss://).
- Игроки на одном сервере из списка в игре видят друг друга.

## Структура
- `server.js` — HTTP-сервер для игры и WebSocket-ретранслятор (комнаты, позиции, удары, постройки)
- `index.html` — сама игра (рядом можно класть картинки и другие файлы)
- `start.bat` / `start.sh` — быстрый запуск

Прогресс игрока (инвентарь, ник) хранится в браузере (localStorage), сервер ничего не сохраняет.
